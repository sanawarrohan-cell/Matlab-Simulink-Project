Battery Voltage Monitoring System using MATLAB and Simulink

Project Overview

This project simulates a battery voltage monitoring system using MATLAB and Simulink. It helps observe battery voltage and understand how voltage conditions can be monitored through simulation.

Tools Used

- MATLAB
- Simulink

Project File

- "actual_battery_simulation.slx" — Simulink model file.

How to Run

1. Download the ".slx" file from this repository.
2. Open MATLAB and launch Simulink.
3. Open "actual_battery_simulation.slx".
4. Run the simulation and observe the output.

Learning Outcomes

- Understanding Simulink models.
- Learning the basics of battery voltage monitoring.
- Observing simulation results.
